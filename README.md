# 數獨遊戲 (Sudoku Game)

一個功能完整、美觀的互動式數獨遊戲。

## 功能特點

✨ **核心功能**
- 🎮 完整的數獨遊戲邏輯
- 🎯 四個難度級別 (簡單、普通、困難、專家)
- ⏱️ 遊戲計時器
- 💡 提示功能
- ✓ 實時驗證和檢查

**用戶體驗**
- 🎨 現代化、響應式設計
- ⌨️ 完整的鍵盤導航支持
- 📱 手機/平板友好
- 🌈 優雅的配色和動畫

## 如何使用

### 1. 基本操作

1. 打開 `index.html` 在瀏覽器中
2. 選擇難度等級
3. 點擊「新遊戲」開始遊戲

### 2. 遊戲控制

| 按鈕 | 功能 |
|------|------|
| **新遊戲** | 開始新的數獨遊戲 |
| **檢查** | 檢查當前進度是否正確 |
| **提示** | 獲得一個隨機空格的答案 |
| **重置** | 恢復到遊戲初始狀態 |

### 3. 輸入方法

- **滑鼠點擊** - 選擇單元格
- **直接輸入** - 在單元格中輸入 1-9 的數字
- **方向鍵** - 上、下、左、右導航
- **Delete/Backspace** - 刪除當前單元格的數字

### 4. 遊戲規則

數獨是一個邏輯益智遊戲：
- 填入 1-9 的數字
- 每行必須包含 1-9 各一次
- 每列必須包含 1-9 各一次
- 每個 3×3 方框必須包含 1-9 各一次

## 難度設定

| 難度 | 初始數字 | 建議時間 |
|------|---------|--------|
| 簡單 (Easy) | 30個 | 10-20分鐘 |
| 普通 (Medium) | 25個 | 20-40分鐘 |
| 困難 (Hard) | 20個 | 40-60分鐘 |
| 專家 (Expert) | 15個 | 60分鐘+ |

## 遊戲截圖說明

- **灰色背景** - 已給定的數字（無法編輯）
- **白色背景** - 可編輯的單元格
- **淺藍色** - 選中的單元格及其所在行/列/方框
- **淺紅色** - 有衝突的數字
- **淺綠色** - 提示高亮

## 鍵盤快捷鍵

| 快捷鍵 | 操作 |
|-------|------|
| ↑ ↓ ← → | 導航到相鄰單元格 |
| Delete / Backspace | 清除當前單元格 |
| 1-9 | 在選中的單元格中輸入數字 |

## 提示

💡 **遊戲技巧**
- 從已知數字最多的行、列或方框開始
- 尋找只有一個可能性的單元格
- 使用「提示」功能獲得幫助（有限制）
- 檢查函數幫助發現錯誤
